## 5. Discrepancias entre el plan y el código, y cómo se resolvieron

1. **`detachSelfPairs` del plan no compila como está escrito.** El `UPDATE` que
   propone usa `$2`/`$3`/`$4` y deja `$1` (el `keepId`) sin usar: PostgreSQL responde
   `could not determine data type of parameter $1`. Se resolvió quitando el parámetro
   sobrante —el lado que sobrevive se conserva tal cual, así que el id que queda no
   hace falta en la sentencia— y documentándolo en el código.
2. **`referencingColumns` devolvía nombres sin esquema** (`album_credits` en vez de
   `public.album_credits`) según el `search_path`. Como `movedRefs` es el rastro que
   E11.8 usará para deshacer, se canonizó a `esquema.tabla` con `quote_ident`; el SQL
   generado sigue siendo válido y el test lo fija.
3. **`grep -rn "slice(0, 50)" src/` no quedaba vacío con los tres recortes de claims
   quitados**: había dos usos más (`src/review/duplicates.ts` y `src/ambiguity/apply.ts`)
   que **no** truncan evidencia, sino el `error_log` del run (pares/decisiones fallidas).
   Se extrajo el tope a la constante nombrada `MAX_FAILURES_IN_LOG` en ambos archivos
   (mismo valor, mismo comportamiento) para que la comprobación de aceptación sea
   inequívoca: ningún `slice(0, 50)` anónimo queda en `src/`. `apply.ts` no lo nombra la
   etapa; se tocó solo por esto y es reversible sin efecto alguno.
4. **`tsconfig.json` no cubría `.mts`** (`include` solo tenía `scripts/**/*.ts`), y la
   sonda que pide el plan es `.mts` (await de nivel superior). Se añadió
   `scripts/**/*.mts` al `include` para que `npm run typecheck` la revise.
5. **`mergeEquivalentCredits` no se podía mover sin dejar `CREDIT_TABLES` atrás**:
   `absorbPerson` (conversión persona → artista/organización) usa esa constante para
   reapuntar créditos. Se mantuvo en `person-corrections.ts` con un comentario que
   explica para qué, y solo se movió la función de equivalencia, como pide el plan.
6. **Deuda observada, fuera del alcance de la etapa** (no se tocó): `absorbPerson`
   borra la fila de `persons` después de rechazar sus claims de nombre, pero no
   reapunta `artist_members` ni `person_organizations`; esas filas caen por
   `ON DELETE CASCADE`. Es material para E11.7 (convertir y dividir).
